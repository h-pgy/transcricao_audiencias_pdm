# Transcrição Audiências do PDM 25-28
Projeto para transcrever automaticamente as falas das audiencias do PDM 25-28 a partir do download dos audios das gravações no youtube e do uso da webservice de speech to text da Azure.

### Dependências:

É necessário instalar o ffmpeg .

#### Windows:

winget install "FFmpeg (Essentials Build)"

#### Ubuntu:

sudo apt update
sudo apt install ffmpeg -y
